# Arquivos da Etapa 1

Este pacote contém `PLANO_IMPLANTACAO.md`, destinado à pasta `docs` do repositório Meu-Study-Hub-TI.

## Como usar

1. Extraia o ZIP.
2. Copie a pasta `docs` para a raiz do repositório correto `Meu-Study-Hub-TI`.
3. Se o VS Code perguntar se deseja mesclar pastas, escolha mesclar. Se já existir um arquivo com o mesmo nome, confira o conteúdo antes de substituir.
4. Abra `docs/PLANO_IMPLANTACAO.md` e confira o texto.
5. No terminal aberto na raiz do repositório, execute `git status`.
6. Se a alteração estiver correta, execute:
   - `git add docs/PLANO_IMPLANTACAO.md`
   - `git commit -m "docs: adiciona plano de implantação"`
   - `git push`

Observação: o documento é um plano inicial e orienta a conferência com o PDF oficial do desafio. Não afirma que a integração Gemini já existe.
