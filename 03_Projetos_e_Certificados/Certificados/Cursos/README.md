# 📚 Cursos

Esta pasta reúne os certificados de **cursos realizados durante minha formação acadêmica e profissional**.

O objetivo é organizar os cursos concluídos e registrar os conhecimentos adquiridos ao longo dos meus estudos na área de Tecnologia da Informação.

## 🎓 Cursos

Cada curso poderá ser registrado com informações como:

* 📌 Nome do curso
* 🏫 Instituição ou plataforma
* 📅 Data de conclusão
* ⏱️ Carga horária
* 🛠️ Tecnologias e conhecimentos estudados
* 📄 Certificado
* 🔗 Link para validação ou acesso ao curso

## 📂 Organização

Os certificados dos cursos poderão ser adicionados nesta pasta seguindo um padrão de organização simples.

Exemplo:

```text
Cursos/
│
├── README.md
│
├── Python/
├── JavaScript/
├── Banco_de_Dados/
├── Inteligencia_Artificial/
└── Outros/
```

## 📈 Evolução

Novos cursos serão adicionados conforme forem concluídos.

Esta seção permitirá acompanhar minha evolução e os conhecimentos desenvolvidos ao longo da minha formação em **Análise e Desenvolvimento de Software**.
