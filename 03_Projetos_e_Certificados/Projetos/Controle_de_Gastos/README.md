# 💰 Controle de Gastos

## 📌 Sobre o projeto

O **Controle de Gastos** é uma aplicação web desenvolvida para auxiliar no **registro e acompanhamento de gastos financeiros**.

O projeto foi desenvolvido como uma atividade prática para aplicar conhecimentos de desenvolvimento web, programação, testes e persistência de dados.

## 🎯 Objetivo

Criar uma aplicação simples para registrar gastos e permitir o acompanhamento dos valores cadastrados e do total das despesas.

## 🛠️ Tecnologias utilizadas

* JavaScript
* Node.js
* Express
* HTML
* CSS
* Jest
* Supabase

## ⚙️ Funcionalidades

A aplicação possui recursos para:

* ➕ Cadastrar gastos
* 📋 Listar gastos registrados
* 🗑️ Excluir gastos
* 💰 Calcular o total dos gastos
* 💾 Persistir informações utilizando banco de dados
* 🧪 Realizar testes automatizados

## 🗄️ Persistência de dados

O projeto utiliza o **Supabase** para armazenamento dos dados.

A aplicação possui integração com uma tabela de gastos no banco de dados, permitindo manter os registros armazenados.

## 🔌 API

O projeto possui uma API desenvolvida com **Express**, com rotas utilizadas para manipular os gastos.
