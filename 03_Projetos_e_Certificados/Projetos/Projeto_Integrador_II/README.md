# 💊 Projeto Integrador II — Sistema de Controle de Medicamentos

## 📌 Sobre o projeto

O **Projeto Integrador II** é um sistema desenvolvido durante o curso de **Análise e Desenvolvimento de Software**, com o objetivo de auxiliar no **controle e gerenciamento de medicamentos controlados**.

O projeto foi desenvolvido como uma atividade prática, aplicando conhecimentos de desenvolvimento de sistemas, banco de dados e organização de software adquiridos durante o curso.

## 🎯 Objetivo

Desenvolver uma aplicação capaz de auxiliar no gerenciamento de medicamentos controlados, proporcionando uma forma mais organizada de registrar e consultar as informações necessárias para o controle dos medicamentos.

## 🛠️ Tecnologias utilizadas

* PHP
* HTML
* CSS
* JavaScript
* MySQL/MariaDB
* XAMPP

## ⚙️ Principais recursos

O sistema possui recursos voltados para:

* 🔐 Autenticação de usuários
* 👤 Controle de acesso
* 💊 Gerenciamento de medicamentos
* 🗄️ Integração com banco de dados
* 📋 Organização das informações do sistema

## 🗃️ Banco de dados

O projeto utiliza um banco de dados para armazenar as informações utilizadas pelo sistema.

**Banco utilizado:**

* MySQL/MariaDB

O ambiente de desenvolvimento utiliza o **XAMPP** para execução local da aplicação e do banco de dados.
